# StillBrief 2.6.3

倒计时改为短促的逐位滚动，移除了模糊和淡出效果。每秒只移动变化的数字，其他数字与冒号保持原位，浅色、深色使用相同动效。

改时间、切回前台、跳过多秒或分钟位数变化时，直接显示正确时间，不连续补播。系统关闭动画时直接更新。

设计参考：[滴答专注](https://help.ticktick.com/articles/7055782010496745472)、[Apple 数字过渡](https://developer.apple.com/documentation/swiftui/contenttransition/numerictext(countsdown:))、[Material 动效时长](https://m1.material.io/motion/duration-easing.html)。本版的 160ms 滚动是针对息间的实现选择。
