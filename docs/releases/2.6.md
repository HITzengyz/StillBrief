# StillBrief 2.6

把时间放在中心，把需要读的消息放在前面。

- 专注页改为圆形进度计时，开始或暂停是主操作；本轮通知数量和下次检查时间并排显示。
- 单次、自动循环使用底部选择弹层，当前模式有勾选标记，两项之间增加细分割线。
- 通知页分开浏览摘要和原始通知，筛选入口收进消息右上角的“更多”菜单。
- 设置按 AI、提醒、通用分组，提供商紧邻 API Key，保存按钮固定在底部。通知权限未开启时提供明确入口。
- 时长选择、下拉菜单、设置行和通知卡片统一间距、图标与分割线；浅色和深色采用相同布局。

App 内保持实时倒计时，桌面小组件继续显示本轮检查时刻。语言和外观切换保留未保存的设置与当前计时。
