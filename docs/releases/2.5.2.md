# StillBrief 2.5.2

让界面更安静，也更容易读。

- 浅色改为暖白分层，深色改为近黑分层，保留青绿操作色；移除下拉选择器和桌面小组件边框。
- 输入框改用圆角填充，聚焦时显示两层柔和内凹层次。API Key 的显示、复制、删除按钮保持在同一行。
- 调整正文与标题字重，深色下减轻字重；计时数字使用等宽数字，正文使用 Android 高质量换行。
- 高级设置展开、收起采用原生布局过渡。复制 API Key 后显示轻微弹出的勾号，2.5 秒后淡出并恢复复制图标。
- 页面切换使用更柔和的缓动；系统关闭动画时直接显示结果。

小组件仍显示本轮检查时刻，App 内仍显示实时倒计时。
