# StillBrief 2.3.1

这版先修复通知和组件的几个边界问题，功能与 2.3 保持一致。

- 不同发送人的相同验证码，不再被合并成同一条；跨通知去重也会核对当前正文。
- 旧码过期后收到同值新码，可以重新转发。有效期内，同一条活动通知只更新提示时仍不会重复发送。
- 即时验证码提取按通知样式处理：聊天通知取最后一条，收件箱样式优先当前正文，长文本样式保留展开后的完整正文。有原始消息时间时用它判断有效期，通知刷新不会延长旧码寿命。
- AI 漏选必留消息时，保留原摘要并补充遗漏事项；兜底预览不会把电话号码、验证码截成半截。内容过长会提示查看原通知。
- 小组件上的“请先完成设置”现在打开设置页，不再误入专注页或历史页。

原有的单次／自动循环、只分析本轮通知、验证码仅转飞书，以及桌面按钮直接执行的方式不变。
