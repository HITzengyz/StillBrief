# 界面样式

息间使用暖白、墨色和青绿。色块区分区域，文字决定层级。

| 部分 | 实现 |
| --- | --- |
| 背景与卡片 | 浅色 `#f5f5f3` / `#fcfcfb`；深色 `#0b0b0a` / `#151515`，控件 `#20201e` |
| 输入框 | 默认无描边，聚焦增加两层低对比内凹层次，不改变大小 |
| 字体 | 正文 400、按钮 500、标题 600；Android 9 起深色请求减轻 40 的字重，最终字形由系统字体提供 |
| 数字 | 计时、分钟和小组件启用 `tnum` 等宽数字 |
| 正文 | Android 高质量换行；输入内容保持原样 |
| 展开与收起 | 使用原生布局过渡，不手工测量内容高度 |
| 复制 | 勾号轻微弹出，2.5 秒后淡回复制图标；编辑、离开页面或切换提供商时取消旧反馈 |
| 拖动 | 圆环直接跟手，每 5 分钟吸附，无回弹 |

摘要一次返回，直接显示。无需逐字打字或模糊效果。网页的 CSS 写法在这里用原生 Android 控件实现；没有增加 UI 依赖。
