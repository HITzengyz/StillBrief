# Privacy ([中文](PRIVACY.md))

We do not collect or receive any of your data. All source code is open.

Notification records and API keys stay on your phone. When analysis is enabled, notification content is sent to your chosen AI provider. With local reminders, the summary appears as a system notification on your phone. With the Feishu bot, Feishu receives the summary, which members of the destination group can also see.

Use a trusted API provider and check any custom endpoint URL. When using Feishu, also check the bot’s destination group.
